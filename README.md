# Infra Linux & Windows Server

Configuration d'une infrastructure réseau complète combinant Linux et Windows Server.

---

## Description

Déploiement d'une infrastructure réseau professionnelle avec des services réseau avancés, des scripts d'administration et une gestion sécurisée des accès.

---

## Services configurés

- DNS : Bind9 (résolution de noms interne et externe)
- DHCP : attribution automatique des adresses IP
- UFW : pare-feu avec règles entrantes et sortantes
- SSH : accès sécurisé sur toutes les machines
- RAID : redondance des données
- Service de fichiers externe : accès depuis l'extérieur
- Service de fichiers interne : partage en réseau local
- Serveur mail : configuration et test

---

## Scripts Bash

- Nettoyage : supprime les fichiers temporaires et anciens logs
- Transfert : déplace automatiquement les fichiers entre serveurs
- Classification : trie et classe les dossiers
- Recherche : recherche dans la base de données

---

## Technologies

- OS : Ubuntu Server, Windows Server
- DNS : Bind9
- Pare-feu : UFW
- Scripts : Bash
